# The-WEBB

##what it is 
The Webb is basically a site that shows the images taken buy the james webb space telescope form 2022 to 2026 .
About the Project

THE WEBB is my first website, built around images captured by the James Webb Space Telescope (JWST) between 2022 and 2026.

The website features a selection of 15 images — three from each year — that I personally chose. It doesn't aim to include every image captured by the telescope instead it presents a small collection through an interactive, space-themed experience.

##Features

Interactive Timeline: Explore 15 selected images across five years by clicking the timeline dots. Hover over a dot to see its date.

Image Popups: Open a popup for each selected image to learn more about it.

Help Button: Use the ? button to learn about the website and how to navigate it.

NASA Picture of the Day: Press the star button to fetch NASA's Astronomy Picture of the Day using an API.

Responsive Layout: Explore the website across different screen sizes.
